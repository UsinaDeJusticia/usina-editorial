# Default output contract

Deliver a clean package the user can copy into WordPress. Do not surround it with technical explanations unless an alert is necessary.

Use this as the default structure, adapting optional fields to the actual material:

## LISTO PARA WORDPRESS

### TÍTULO
A specific, accurate title written for readers. Do not include markup such as `#` or `<h1>`.

### EXTRACTO
1-2 self-sufficient sentences that complement the title.

### CATEGORÍA
Exactly one current category from `site-contract.md`.

### TAGS SUGERIDOS
Include only useful discoverability/navigation tags. Omit this section if there are no worthwhile tags.

### IMAGEN DESTACADA
If an image was supplied, identify the best option. If none was supplied and a suggestion would be useful, describe the kind of image that would fit. Omit when unnecessary.

### ALT
Write factual alt text only for an actual or clearly identified featured image. Omit if there is no image to describe.

### CUERPO
Start directly with the article lede. Do not repeat the title or publication date.

Use H2-style subheadings (`##`) only where they help structure the article. Keep the structure adaptive to the content type.

### DOCUMENTOS / ENLACES
List only the supporting documents or links the user should attach or insert. Omit if there are none.

### ALERTA EDITORIAL
**Conditional.** Include only when the silent editorial control detects an issue that requires human review. State:

- what was detected;
- where it appears;
- whether it was omitted, neutralized, or left unresolved in the draft;
- what the user should verify before publishing, if anything.

If there is no real alert, this heading must not appear.

## Output quality checks

Before delivering:

- title and excerpt do not simply repeat one another;
- opening paragraph explains the event without requiring the attachments;
- article depth matches the material rather than a fixed word count;
- facts added from research are supported;
- victim-centered framing is preserved when crime is involved;
- legal status is accurate;
- no title/date duplication inside the body;
- category is one of the six current categories;
- attachments support the article but do not contain its only substantive explanation;
- alert appears only when genuinely needed.
